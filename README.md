# 複習小書房（國英數自社複習平台）

老師把考卷丟進資料夾或後台 → 平台自動拆題、分類成題目草稿（不用 AI、不需金鑰） → 老師在審核頁面確認 → 學生在網頁（電腦、平板、手機）選範圍玩遊戲複習。
題庫是一般的資料夾與 JSON 檔，可以放在 Google Drive / OneDrive / Dropbox 同步資料夾，老師在任何電腦更新，學生下一次出題就看得到。

```
待匯入/ ──npm run import──▶ 待審核/ ──/admin 通過──▶ 題目/ ──▶ 學生端遊戲
  (PDF/Word/文字)   自動整理         老師審核         正式題庫
        └─原檔移到 來源/版本/年級/，紀錄寫入 老師/投稿紀錄.json
```

## 快速開始

**最簡單的方式**：安裝 Node.js（https://nodejs.org ，選 LTS 版）後，在專案資料夾點兩下 `啟動平台-Windows.bat`（Windows）或 `啟動平台-Mac.command`（Mac；第一次請按右鍵 →「打開」）。第一次會自動安裝套件，接著瀏覽器會打開平台。

用指令啟動：

需要 Node.js 18.17 以上（建議 22 LTS）。

```bash
npm install          # 安裝套件
npm run validate     # 檢查題庫格式
npm start            # 學生端 http://localhost:3000 ，老師審核 http://localhost:3000/admin
npm test             # 自動測試
```

同一個網路的平板要連線時，用電腦的區網 IP，例如 `http://192.168.1.20:3000`（電腦防火牆需允許 3000 埠）。

## 一、連結題庫資料夾（執行步驟）

### 1. 建立資料夾結構

在雲端硬碟（或本機）建立一個題庫資料夾，例如 `國英數題庫`，裡面放這幾個子資料夾（沒有的話程式會自動建立）：

```
國英數題庫/
├── 待匯入/            ← 老師把考卷、講義丟這裡
│   ├── 數學/南一/國二/段考一.pdf      （建議：科目/版本/年級/檔名）
│   └── 翰林/國一/英文第一課講義.docx  （科目可省略，會從檔名與內容判斷）
├── 待審核/            ← 匯入後的草稿（程式產生，到 /admin 審核）
├── 題目/              ← 正式題庫（審核通過才會出現在這裡）
│   ├── 國文/  英文/  數學/  自然/  社會/
├── 圖片/              ← 題目圖片（匯入切出的圖在 圖片/匯入/）
├── 來源/              ← 處理過的原檔，自動依 版本/年級 歸檔
├── 老師/投稿紀錄.json  ← 每次匯入的紀錄
├── 遊戲/              ← 上傳的遊戲（後台新增或老師投稿，程式產生）
└── 索引/              ← 自動產生，不用理它
```

**放檔與命名建議**
- 資料夾名稱會被當成可信的資訊：科目用 `國文`／`英文`／`數學`／`自然`／`社會`；年級用 `國一`～`國三`（也接受 `七年級`～`九年級`、`小一`～`小六`、`高一`～`高三`）；其他名稱視為版本（`南一`、`翰林`、`康軒`…）。
- 檔名會變成草稿檔名（`段考一.pdf` → `待審核/段考一.json`），用看得懂的中文名稱即可，例如 `南一國二數學第一次段考.pdf`。同名檔案會自動加 `(2)`。
- 一份考卷一個檔案。檔名寫上科目、年級、上下冊、版本（例如 `南一數學2上第一次段考.pdf`）可以讓自動分類更準。
- 考卷若附參考答案，請一起放進同一個檔案，才會自動填入答案；沒有答案的題目會標示「需審核」，不會亂猜。
- 支援有文字的 `.pdf`、`.docx`（含內嵌圖片）、`.txt`；掃描檔與照片讀不到文字，請改用 Word 或貼上文字。

### 2. 讓電腦同步這個資料夾

伺服器是讀「電腦上的資料夾」，不能直接讀 Google Drive 的分享網址，所以要先讓雲端資料夾同步到執行 `npm start` 的那台電腦。

**Google Drive（使用分享連結的資料夾，例如 `https://drive.google.com/drive/folders/...`）**

1. 用要執行伺服器的那台電腦登入 Google 帳號，打開分享連結。
2. 如果資料夾是別人分享給你的：在資料夾名稱旁的選單選「整理」→「新增捷徑」→ 放到「我的雲端硬碟」。**分享給你的資料夾不加捷徑，電腦版不會同步。**資料夾本來就在你的「我的雲端硬碟」裡則不用做這步。
3. 安裝「Google 雲端硬碟電腦版」並登入同一個帳號，在「偏好設定 → Google 雲端硬碟」選「鏡像檔案」；或在資料夾上按右鍵選「可離線使用」。
4. 在檔案總管 / Finder 找到資料夾，確認裡面能看到 `題目`、`待匯入` 等子資料夾（第一次可以先建立空的 `題目` 資料夾）。路徑通常是：
   - macOS：`/Users/你的帳號/Library/CloudStorage/GoogleDrive-帳號@gmail.com/我的雲端硬碟/國英數題庫`
   - Windows：`G:\我的雲端硬碟\國英數題庫`
5. 共用的老師要有「編輯者」權限，才能把考卷丟進 `待匯入/`；學生不需要任何雲端權限，他們只連網頁。

**OneDrive**：路徑通常是 `C:\Users\你的帳號\OneDrive\國英數題庫`，在資料夾上按右鍵選「一律保留在此裝置上」。
**Dropbox**：`~/Dropbox/國英數題庫`。

> 一定要設定成「保留在本機」，否則雲端只有捷徑，程式讀不到檔案內容。

### 3. 修改 config.json

```json
{
  "dataDir": "/Users/你的帳號/Library/CloudStorage/GoogleDrive-帳號@gmail.com/我的雲端硬碟/國英數題庫"
}
```

Windows 路徑要把 `\` 寫成 `\\` 或 `/`，例如 `"G:/我的雲端硬碟/國英數題庫"`。改完執行 `npm run validate` 確認讀得到題目，再 `npm start`。

多位老師共用時：每位老師的電腦都同步同一個雲端資料夾即可；只需要一台電腦執行 `npm start` 給學生連線。若多台電腦同時開伺服器，雲端可能產生 `索引/` 的衝突副本，不影響使用（可把 `indexFile` 改成本機路徑避免）。

## 二、題目匯入（不需金鑰、免費）

建議直接用後台「匯入考卷」頁上傳；也可以把檔案放進 `待匯入/` 後雙擊 `匯入考卷-Windows.bat` 或執行 `npm run import`（會先列出清單，輸入 y 才處理）。

1. **抽取文字**：PDF 讀文字層並記下每行在頁面上的位置；Word 讀文字與內嵌圖片；貼上的文字存成 `.txt`。
2. **自動拆題**：依題號與 (A)(B)(C)(D)／①②③④ 拆成選擇題；答案取自題號前的 `( B )`、題後的 `答：B`、卷末的 `答案 1.B 2.(C)` 或 `1~5 BCADB`；`【解析】` 會放進解析；`√12`、`x²` 轉成 KaTeX。
3. **自動分類**（優先順序：資料夾 > 檔名 > 考卷開頭標題 > 題目內容）：
   - 科目：資料夾或檔名寫「數學」「社會」等；沒有的話依題目用詞判斷（英文比例、數學符號、各科關鍵詞）。
   - 年級與冊：`2上` → 國二・第三冊、`九年級下` → 國三・第六冊、`第三冊`、`國二` 等寫法都看得懂。
   - 版本：南一、翰林、康軒、部編、龍騰……
   - 章節：考卷中的「第二章 …」「1-2 乘法公式」標題，會套用到後面的題目。
   - 難度：依題目長度、是否有圖表、是否「何者正確」、是否有分數根號等估計 1～3。
   - 截圖：題目寫「如圖／附圖／下表」時，自動截取 PDF 上那一題的範圍（題目＋圖）當題目圖片。
4. **編號**：依「科目-年級-流水號」自動編號。缺答案、缺章節等必要欄位的題目標示「需審核」，其他直接是「完整」。
5. 原檔移到 `來源/版本/年級/`，紀錄寫入 `老師/投稿紀錄.json`。**絕對不會直接寫入 `題目/`。**

## 三、老師後台 /admin（密碼登入）

學生首頁右下角「老師後台」進入並輸入密碼。密碼寫在專案資料夾的 `本機設定.json`（例如 `{ "admin_password": "0928" }`），這個檔案不會上傳到 GitHub；沒有這個檔案時就不需要密碼。登入後會記住 30 天，右上角可登出。所有老師工作都在這裡完成，不需要開資料夾或打指令：

| 分頁 | 做什麼 |
|---|---|
| **總覽** | 待匯入檔案數、待審核題目數、待發布遊戲數、各科題數、最近匯入紀錄 |
| **匯入考卷** | 選科目／版本／年級 → 上傳 PDF、Word、照片（可拖曳、多選）→ 勾選確認 → 開始匯入，畫面顯示進度；完成後按「前往審核題目」 |
| **題目審核** | 逐題編輯、補答案與章節；**通過**才寫入 `題目/`，**退回**要寫原因 |
| **遊戲管理** | 試玩、發布、退回、下架老師投稿的遊戲，或自己新增遊戲 |

- **不用金鑰、免費**：所有匯入都由平台自動拆題與分類（見上一節），也可以「貼上題目文字」或在題目審核頁「＋ 手動新增一題」。
- **數學式（KaTeX）**：題目、選項、解析中用 `$...$` 包住 LaTeX，例如 `$\frac{1}{2}$`、`$x^2+6x+9$`、`$\sqrt{3}$`，學生端、題庫遊戲與審核頁的「學生畫面預覽」都會顯示成數學式。KaTeX 放在 `public/vendor/katex/`，不需要網路。
- **審核更快**：題目審核頁上方的「批次處理」可以把同一份考卷的科目、版本、年級、冊、章、節一次補齊；補齊後按「一鍵通過所有已完整的題目」，只剩少數缺答案的題目需要逐題處理。
- 原本的資料夾流程（把檔案放進 `待匯入/`、雙擊 `匯入考卷-Windows.bat` 或 `npm run import`）仍可使用，放進資料夾的檔案也會出現在「匯入考卷」頁。
- 要改密碼：用記事本打開 `本機設定.json` 修改後重新啟動平台；改密碼後，已登入的人會被登出。刪掉這個檔案就不需要登入。

## 四、學生端

流程：**學科 → 遊戲 →（用題庫的遊戲才需要）版本 → 年級與冊 → 章節 → 開始**。版面針對平板設計，手機直式也能操作；學生端不會顯示檔名、資料夾或題目歸屬路徑，答案只在作答後由伺服器回傳。

- **學科分區**：首頁有「國文、英文、數學、自然、社會、其他」六區，顯示每科的題數與遊戲數。科目代碼：國文 C、英文 E、數學 M、自然 B、社會 S（題號例如 `B-N1-0001`、`S-N1-0001`）。
- **先選遊戲**：卡片上是遊戲畫面截圖。標示「選範圍・用題庫出題」的遊戲才會進入選範圍；標示「直接開始」的遊戲（例如吃作業、根式魔法學院）點了就玩。同一科選過範圍後，換遊戲會直接帶到「開始」，可按「更改範圍」重選。
- **全螢幕**：按「開始遊戲」或點直接開始的遊戲時自動進入全螢幕；左上「離開」、右上「全螢幕／縮小」可切換，按 Esc 也會縮小。iPhone 的 Safari 不支援網頁全螢幕，會改為佔滿整個瀏覽器畫面（加到主畫面後開啟可隱藏網址列）。
- **其他**：生活管理、職業教育、社會技巧等特需領域遊戲，依分類列出，不需選範圍。

### 新增遊戲

每個遊戲是 `public/games/<名稱>/game.js` 的 ES 模組，預設匯出 `createGame(host)`：

```js
export default function createGame(host) {
  return {
    start(questions) { /* 收到題目（不含答案）：{ id, 科目, 題幹, 選項, 難度, 圖片 } */ },
    render() { /* 把畫面畫到 host.root */ },
    async onAnswer(questionId, choice) {
      const r = await host.check(questionId, choice); // { correct, 答案, 解析 }
      return r;
    },
    destroy() { /* 選填：離開時清理 */ },
  };
}
// host.finish({ score, correct, total, 紀錄 }) 結束並顯示成績；host.exit() 不計分離開
```

然後在 `public/games/registry.json` 加一筆（`科目` 限定適用科目、`預設題數`、`全版面` 等）。遊戲不可內嵌題目，一律使用傳入的 questions。
已有的單檔 HTML 遊戲可用 `iframeGame()` 包裝（見 `public/games/principal/game.js`），遊戲內引用 `/games/_shared/bridge.js`，用 `GameBridge.questions()` 取題、`GameBridge.check()` 驗證答案。

## 五、遊戲管理與老師投稿

### 管理員新增遊戲（/admin/games.html）
後台上方切換「題目審核／遊戲管理」。按「＋ 新增遊戲」，填名稱、說明、分類，選擇是否使用題庫（要勾適用科目），上傳 `.zip`（最外層要有 `index.html`；多包一層資料夾也可以）或單一 `.html`，可附封面截圖。勾「直接發布」就立刻上架，否則先放在待審核。

每個遊戲可以：**預覽試玩**（題庫遊戲會用題庫裡的題目試玩）、**編輯**（改資訊、替換遊戲檔或封面）、**發布**、**退回**（要寫原因）、**下架**、**刪除**。

### 老師投稿（/submit/，學生首頁右下角也有連結）
其他老師在投稿頁填資料、上傳遊戲檔或**貼上遊戲連結**（例如 Gemini、Canva 的分享網址；連結遊戲只是掛在平台上，不能用題庫，若網站不允許嵌入，學生可按「在新視窗開啟」），可標示適用年級與章節（學生頁會顯示成標籤並依年級、章節排序），一律進入「待審核」，**管理員在後台試玩後按「發布」學生才看得到**。投稿頁提供 [遊戲範本](public/submit/template.html) 與 GameBridge 說明。
`config.json` 的 `submit_password` 可設定投稿密碼（空字串＝知道網址就能投稿，但仍須審核）；`gameUpload.maxZipMB` 設定上傳上限（預設 30MB）。

### 安全性
- 上傳的遊戲放在 `題庫/遊戲/<編號>/檔案/`，由 `/ugames/<編號>/` 提供，並加上 CSP `sandbox`（不含 `allow-same-origin`）：遊戲在瀏覽器眼中是「另一個網站」，讀不到平台的資料、Cookie，也呼叫不了後台 API。題庫遊戲只能透過 GameBridge 取得「不含答案」的題目與批改結果。
- 管理 API 會拒絕跨站送來的請求（防止惡意遊戲偷偷按「發布」）。
- 只接受網頁、圖片、音效、字型等檔案類型；`.exe` 等其他檔案會被略過並告知。
- 沙盒中的遊戲無法永久保存 `localStorage`（平台自動換成「本次有效」的版本，遊戲不會當掉）。
- 未發布的遊戲只有後台（`/admin/preview/…`）能開啟。

### 遊戲截圖（選遊戲卡片的封面）
內建 15 個遊戲的封面已放在 `public/games/<id>/cover.jpg`。新增遊戲後要自動截圖：

```bash
npm i -D playwright && npx playwright install chromium   # 第一次需要
npm run screenshots              # 擷取還沒有封面的遊戲（含已發布的上傳遊戲）
npm run screenshots -- --all     # 全部重拍
npm run screenshots -- quiz      # 只拍指定 id
```

題庫遊戲會實際走一次選範圍流程後截圖，因此題庫中要有該科題目。也可以直接在後台「編輯」上傳自己的截圖。

## 技術選擇

後端 Node.js + Express、前端純 HTML/CSS/JavaScript（ES 模組，不需編譯）。前後端同一種語言、JSON 是原生格式、安裝只需 `npm install`。匯入功能使用 `pdfjs-dist`（PDF 文字與頁面圖）、`@napi-rs/canvas`（繪圖與切圖，免編譯）、`mammoth`（Word）、`@anthropic-ai/sdk`（Claude API）。

## 題目格式

一個 JSON 檔可以放**一個題目物件**，也可以放**題目陣列**。檔名、子資料夾名稱沒有限制（`.` 或 `~` 開頭的暫存檔會被略過）。

```json
{
  "id": "M-N2-0153",
  "題幹": "將 (x + 3)² 展開後，下列何者正確？",
  "選項": ["x² + 9", "x² + 6x + 9", "x² + 3x + 9", "x² + 6x + 6"],
  "答案": 1,
  "難度": 2,
  "圖片": null,
  "解析": "和的平方公式……",
  "歸屬": [
    { "版本": "南一", "年級": "國二", "冊": "第三冊", "章": "第1章 乘法公式與多項式", "節": "1-1 乘法公式" },
    { "版本": "翰林", "年級": "國二", "冊": "第三冊", "章": "第1章 乘法公式與多項式" }
  ]
}
```

| 欄位 | 必填 | 說明 |
|---|---|---|
| `id` | ✅ | `科目代碼-年級代碼-流水號`。科目代碼、年級代碼定義在 config.json（預設 C/E/M；P1–P6、N1–N3、H1–H3），流水號至少 4 位數 |
| `題幹` | ✅ | 非空字串 |
| `選項` | ✅ | 至少 2 個非空字串 |
| `答案` | ✅ | 正確選項的索引，**從 0 開始**（第一個選項是 0） |
| `難度` | ✅ | 1、2、3 |
| `圖片` | | `null`、空字串、相對於 `圖片/` 的路徑（例如 `數學/M-N2-0153.png`），或 `https://` 網址 |
| `解析` | | 作答後才會顯示（擴充欄位） |
| `歸屬` | ✅ | 至少一筆；每筆要有 `版本`、`年級`、`冊`、`章`，`節` 可省略。名稱不可包含半形 `/` |

同一題要出現在多個版本或章節時，在 `歸屬` 多加幾筆就好，題目內容只存一份。

## 索引

`索引/題目索引.json` 依「版本 → 年級 → 冊 → 章（→ 節）」建立樹狀結構，**每個節點都記錄它底下所有題目的 ID**；另外記錄每個 ID 位在哪個檔案的第幾題。

每次 API 請求都會：
1. 掃描 `題目/` 下所有 JSON 檔，以「路徑 + 大小 + 修改時間」算出指紋
2. 與索引檔記錄的指紋比對，相同就直接使用；新增、修改、刪除檔案或索引檔損毀時自動重建
3. 題目內容每次都從原始 JSON 檔重新讀取，不做快取

所以老師存檔後，學生下一次出題就能看到新內容，不需要重啟伺服器。有錯誤的題目、重複 ID 的第二個以後的題目不會進入索引（伺服器會在終端機印出原因）。

## API

### `GET /api/games`
內建與已發布的上傳遊戲清單（`使用題庫`、`科目`、`封面`、`外部`）。

### `GET /api/tree[?subject=M]`
回傳科目清單與範圍樹，每個節點只有 `名稱`、`層級`、`路徑`、`題數`、`子層`，不含題目 ID 與內容。加上 `subject` 時題數只計算該科。

### `GET /api/questions?scope=...&count=10&subject=...`
- `scope`：範圍路徑，用 `/` 分隔各層，可以只到任一層，例如 `南一`、`南一/國二/第三冊`。**可重複帶多個**：`?scope=南一/國二&scope=翰林/國二/第三冊`。同一題同時在多個範圍裡只會出現一次。
- `count`：題數，預設 10，上限為 config 的 `maxCount`（50）
- `subject`：科目代碼或名稱，可用逗號多選，例如 `M`、`數學`、`M,E`
- `difficulty`（擴充）：`1,2` 之類
- 回傳的題目只有 `id`、`科目`、`題幹`、`選項`、`難度`、`圖片`，**不含答案、解析**

### `POST /api/check`
```json
{ "answers": [ { "id": "M-N2-0153", "choice": 1 } ] }
```
回傳每題 `correct`、正確 `答案` 與 `解析`，以及總答對數。

### `GET /api/status`
題目數、錯誤 / 警告數量、索引更新時間。

## 驗證題庫

```bash
npm run validate                       # 有錯誤時 exit code 1
node scripts/validate.js --strict      # 連警告也視為失敗
node scripts/validate.js other.json    # 使用其他設定檔
```

輸出範例（每則都附檔案、行號、第幾題、ID、欄位）：

```
▌題目/數學/錯誤示範.json
  [錯誤] 題目/數學/錯誤示範.json:3 [第 1 題, id=M-N2-0153] 欄位「id」：ID「M-N2-0153」重複，第一次出現在 數學/國二.json 第 3 行（第 1 題）；此題將不會被使用
  [錯誤] 題目/數學/錯誤示範.json:10 [第 2 題, id=M-N2-160] 欄位「答案」：索引 4 超出選項範圍：此題有 4 個選項，答案應為 0 ~ 3（第一個選項是 0）
  [錯誤] 題目/數學/錯誤示範.json:10 [第 2 題, id=M-N2-160] 欄位「歸屬[0].冊」：缺少欄位
  [警告] 題目/數學/錯誤示範.json:10 [第 2 題, id=M-N2-160] 欄位「圖片」：找不到圖片檔「數學/不存在.png」

▌題目/英文/語法錯.json
  [錯誤] 題目/英文/語法錯.json:4:3：JSON 語法錯誤：Expected ',' or '}' after property value ...（常見原因：少了逗號、多了結尾逗號、用了中文引號「」或單引號）
      → "選項": ["a","b"]
```

檢查項目：JSON 語法（含行列）、最外層型別、必填欄位、型別、ID 格式與代碼、跨檔案 ID 重複、答案索引範圍、難度範圍、選項數量 / 空白 / 重複、圖片路徑與檔案是否存在、歸屬每一筆的必填欄位、歸屬重複、未知欄位（可能是打錯字）。

## 測試

```bash
npm test
```

測試會把 `題庫/` 複製到暫存資料夾，不會動到真正的題庫。內容包括：驗證規則與錯誤位置、API 不洩漏答案、多範圍去重、科目篩選、作答驗證、新增 / 修改 / 刪除題目後立即反映、索引損毀自動重建；匯入流程（以假的 Claude 回應測試切圖、編號、移檔、紀錄，確認不寫入 題目/）；審核流程（排序、退回、通過、編號衝突、密碼、圖片上傳）。測試不會呼叫 Claude API。

本機手動測試學生端：`npm start` 後用瀏覽器開 `http://localhost:3000`，按 F12 開啟裝置模擬（iPad / iPhone）可檢查平板與手機版面。

手動測試：

```bash
curl -s localhost:3000/api/tree
curl -s -G localhost:3000/api/questions --data-urlencode 'scope=翰林' --data-urlencode 'scope=南一/國二' -d count=5
curl -s -X POST localhost:3000/api/check -H 'Content-Type: application/json' -d '{"answers":[{"id":"M-N2-0153","choice":1}]}'
```

## 已知限制

- 答案在作答後才由伺服器回傳，開發者工具看不到尚未作答的答案；但學生仍可對同一題反覆呼叫 `/api/check` 試出答案。若要正式計分，需要加上「每題只能作答一次」的機制。
- 自動截圖是截取整題的範圍，偶爾會多帶到相鄰題目的一小段，可在審核頁上傳替換。
- 每題只支援一張圖片；一題有多張圖時只自動切出第一張，並在備註提示。
- Word 中的 EMF/WMF 向量圖無法轉成圖片，建議先另存為 PDF 再匯入。
- 自動整理是規則解析，適用格式整齊、有文字的考卷；掃描檔與照片讀不到文字。科目、章節是推斷結果，請在審核頁確認。
- 遊戲投稿目前是第一階段：老師投稿 → 管理員審核後發布。老師沒有個人帳號，無法自行修改已投稿的遊戲（請重新投稿，或由管理員在後台「編輯」替換）。
- 上傳遊戲若需要連外網（CDN、外部 API）仍可運作，但學校網路擋外網時會失效；建議把需要的程式庫一起打包進 ZIP。
