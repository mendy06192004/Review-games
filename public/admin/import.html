1 上傳考卷

先選好科目、版本、年級（AI 會用來判斷章節與題號），再選檔案。支援 PDF、Word（.docx）、照片（.jpg / .png），可一次選多個。

2 確認要匯入的檔案

勾選要交給 AI 整理的檔案。處理完的原檔會自動歸檔，題目先變成「草稿」，不會直接給學生。

載入中…

還沒有 Claude API 金鑰。AI 整理需要金鑰；貼上後只保存在這次開啟的平台中，關掉黑色視窗就會清除，不會寫進任何檔案。

金鑰要到 console.anthropic.com 登入後，在「API Keys」按「Create Key」產生，是一長串以 sk-ant- 開頭的文字（只會顯示一次，請完整複製）。帳戶需要先在 Billing 儲值才能使用。注意：Claude.ai 的訂閱（Pro / Max）和 API 金鑰是分開的。

想要每次啟動都自動有金鑰：雙擊專案資料夾裡的「設定金鑰-Windows.bat」一次即可。
