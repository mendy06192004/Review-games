分享你做的遊戲

上傳後會先交給管理員試玩審核，通過後才會出現在學生頁面。

  1. 準備遊戲檔：單一 .html 檔，或把整個遊戲資料夾壓成 .zip（最外層要有 index.html）。
  2. 想用平台的題庫出題？下載 遊戲範本，照裡面的註解修改。
  3. 附上一張遊戲畫面截圖當封面（選填），學生選遊戲時看得到。
題庫遊戲的寫法（GameBridge）

在網頁中加入 <script src="/games/_shared/bridge.js"></script>，就能使用：

GameBridge.requireBank('遊戲名稱')   // 沒有從平台開啟時顯示提示，回傳 false
GameBridge.questions()               // Promise<題目陣列>：{ id, 科目, 題幹, 選項[], 難度, 圖片 }（不含答案）
GameBridge.check(題目id, 選項索引)    // Promise<{ correct, 答案, 解析 }>，由伺服器批改
GameBridge.finish({ score })         // 遊戲結束，平台會顯示成績

注意：上傳的遊戲在安全沙盒中執行，localStorage 只在這次遊玩有效，關掉就清除；也無法讀取平台的其他資料。
